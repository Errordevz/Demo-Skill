# Example requests for Demo Toolkit

- “Research this claim, prioritize official sources, and show what remains uncertain.”
- “Open this website, inspect its current UI, and report usability issues with evidence.”
- “Analyze this public video link. Use actual frames or transcript if available; don't guess from the caption.”
- “Review this repository, find the bug, make a minimal fix, run relevant tests, and report exact results.”
- “Compare these two CSV files, validate their schemas, and explain the meaningful differences.”
- “Inspect this binary statically and create an evidence-based report without executing it.”
- “Try the task using tools already available. Don't ask me for API keys; tell me if a capability isn't available.”
